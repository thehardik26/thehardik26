## 💫 About Me:
- 🔭 I'm currently working on full-stack web applications using **React.js**, **Tailwind CSS**, and **Django REST Framework** / **FastAPI** with **MySQL**.
- 👯 I'm looking to collaborate on open-source full-stack projects, scalable RESTful APIs, and microservices architecture.
- 🤝 I'm looking for help with advanced asynchronous performance optimization and database indexing in production MySQL.
- 🌱 I'm currently learning microservice orchestration with FastAPI, caching strategies (Redis), and modern Docker workflows.
- 💬 Ask me about **React**, **Tailwind CSS**, **Django**, **DRF**, **FastAPI**, and relational database design.
- ⚡ Fun fact: Django gives you the "batteries included," but FastAPI brings the speed — combining both gives you the best of both worlds!
